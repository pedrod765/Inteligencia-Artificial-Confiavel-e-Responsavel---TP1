# Inteligencia-Artificial-Confiavel-e-Responsavel---TP1
Projeto de aprendizagem ativa sensível à equidade para previsão de respostas a candidaturas, utilizando Random Forest e supervisão humana (Human-in-the-Loop). Compara diferentes estratégias de seleção de dados, analisando o desempenho preditivo, a equidade entre grupos e o impacto da intervenção humana.

Trabalho realizado por Pedro Miguel Gonçalves Dias e Pedro Pais Dinis.
